### How to supply real NSE data for genuine backtest validation

1. Download NSE Bhavcopy (daily) from:  
   https://www.nseindia.com/all-reports → Equity → Bhavcopy (CSV)

2. Format required (any of these column names accepted):

   ```
   Symbol  | Ticker | Scrip
   Date    | Trading_Date | Datetime | Timestamp
   Open    | Open_Price
   High    | High_Price
   Low     | Low_Price
   Close   | Close_Price | LTP | Last_Price
   Volume  | Vol | Traded_Volume
   ```

3. Place your file in this directory (or any local path accessible to the backend).

4. **Do not commit real data files to Git.**  
   Add your filename to `.gitignore`:
   ```
   backend/src/indian/backtest/fixtures/*.real.csv
   ```

5. Call the importer:
   ```typescript
   import { nseHistoricalCsvImporter } from '../backtest/NseHistoricalCsvImporter';
   import { readFileSync } from 'fs';

   const csv = readFileSync('./path/to/your/data.csv', 'utf8');
   const result = nseHistoricalCsvImporter.parseCSV(
     csv,
     'your_data.csv',    // sourceFileName for audit trail
     'NSE_BHAVCOPY',     // dataSource
     'RAW'               // priceAdjustment (RAW or ADJUSTED)
   );
   ```
